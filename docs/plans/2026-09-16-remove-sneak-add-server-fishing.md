# 몰래먹기 제거·서버 낚시 계획

1. 게임 레지스트리와 제목 상수에서 `capybara-sneak`을 제거해 로비, 목록, SEO, 사이트맵에서 자동 제외한다.
2. 게임 소스, 테스트, 원본 이미지, 공개 이미지를 삭제하고 직접 경로가 404인지 확인한다.
3. 낚시 확률과 15~60초의 무작위 완료 시각을 백엔드 상수·Supabase RPC가 결정하게 하고, 가방은 DB에만 저장한다.
4. 화면 복귀 시 서버 시각으로 경과분을 정산해 비활성 탭에서도 낚시가 이어지게 한다.
5. 7종마다 서로 다른 움직임을 적용하고 모든 결과에 반짝임, 황금인어에는 강화된 반짝임을 적용한다.
6. 프론트 타입 검사·테스트와 백엔드 마이그레이션·전체 테스트·빌드, 실제 브라우저를 검증한다.
