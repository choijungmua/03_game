# 광고 배치 계획

## 목표

1. 플레이와 재도전을 방해하지 않는다.
2. 검색으로 들어온 사용자가 다른 게임까지 이어서 플레이하게 한다.
3. 승인 직후에는 적은 광고로 시작하고, 실제 지표로만 늘린다.

광고는 신규 사용자를 데려오는 기능이 아니다. 신규 유입은 게임별 공략 페이지, 검색 노출, 공유 링크가 담당하고 광고는 그 방문을 수익화한다.

## 배치 원칙

- `playing`, 카운트다운, 일시정지 중에는 광고를 마운트하거나 요청하지 않는다.
- 광고는 게임 캔버스와 조작 영역 밖에만 둔다.
- 점수와 `다시 하기` 버튼 사이에는 광고를 넣지 않는다.
- 전면광고, 팝업, 강제 대기, 자동 새로고침 광고는 사용하지 않는다.
- 로비는 하나의 상호작용 화면이므로 광고를 넣지 않는다.
- 승인 전에는 현재 placeholder를 실제 광고로 교체하지 않는다.

## 1차 배치

| 우선순위 | 위치 | 형식 | 노출 시점 | 이유 |
| --- | --- | --- | --- | --- |
| 1 | 게임 공략 페이지의 공략 본문 아래, FAQ 위 | 반응형 디스플레이 1개 | 페이지 진입 시 | 검색 유입과 체류 시간이 있고 게임 조작을 방해하지 않음 |
| 2 | 게임 결과 화면의 `다시 하기`·`홈으로` 버튼 아래 24px 이상 간격 | 모바일 기준 높이 90px 안팎의 반응형 배너 1개 | 결과가 확정된 뒤에만 | 재도전 CTA를 가리지 않으면서 반복 방문을 수익화 |
| 3 | `/games` 게임 목록 맨 아래 | 반응형 디스플레이 1개 | 목록 페이지 진입 시 | 게임 선택을 끊지 않고 목록 탐색 방문을 수익화 |

게임 결과 광고는 사용자가 바로 `다시 하기`를 누르면 요청을 취소하거나 즉시 언마운트한다. 광고 로딩 때문에 재시작을 기다리게 하지 않는다.

## 넣지 않는 위치

- `/` 로비와 로비 메뉴
- 게임 시작 화면의 시작 버튼 주변
- 플레이 화면, HUD, 캔버스, 모바일 조작 버튼 주변
- 점수와 재도전 버튼 사이
- 개인정보처리방침, 이용약관, 문의 페이지
- 화면 하단을 덮는 앵커 광고와 페이지 전환 전면광고

AdSense 자동 광고를 켤 경우에도 오버레이 형식은 끄고 `/`와 `/games/*`는 URL 제외 대상으로 둔다. 게임 페이지 광고는 코드에서 상태를 확인하는 수동 슬롯만 사용한다.

## 유입 확대 동선

1. 검색 결과 → 게임별 공략 페이지
2. 공략 페이지 → `게임 시작` 버튼
3. 게임 종료 → `다시 하기`를 첫 번째 행동으로 유지
4. 게임 소개 하단 → 관련 게임 6개
5. 결과 공유 → 해당 게임의 고유 URL

공략 페이지는 게임마다 고유한 제목, 설명, 조작법, 공략 팁, FAQ를 유지한다. 얇은 페이지를 대량 생성하지 않고 실제 게임이 있는 페이지만 검색에 노출한다.

## 측정 지표

광고 적용 전 7일을 기준값으로 기록하고 적용 후 14일과 비교한다.

- 게임 시작 수
- 결과 도달 수
- 결과 후 재도전율
- 세션당 플레이 횟수
- 관련 게임 클릭률
- 공유 완료 수와 공유 링크 유입 수
- 공략 페이지 → 게임 시작 전환율
- 광고 노출 가능 비율, 페이지 RPM
- 이탈률, Core Web Vitals, CLS

광고 적용 후 재도전율이 기준값보다 10% 이상 하락하거나 CLS가 0.1을 넘으면 결과 광고를 먼저 제거한다.

## 출시 순서

### 0단계: 심사 중

- 현재 AdSense 확인 스크립트와 `ads.txt`만 유지한다.
- 실제 광고 슬롯은 활성화하지 않는다.

### 1단계: 승인 후 1주

- 공략 페이지 광고 1개만 전체 게임에 적용한다.
- 자동 광고의 오버레이 형식은 사용하지 않는다.
- 7일 동안 검색 유입, 이탈률, CLS를 확인한다.

### 2단계: 승인 후 2주

- 트래픽이 많은 게임 2개에만 결과 광고를 추가한다.
- 광고는 공용 결과 액션 아래에서 `result` 상태일 때만 마운트한다.
- 재도전율과 세션당 플레이 횟수를 14일간 비교한다.

### 3단계: 검증 후

- 재도전율 하락이 5% 미만이고 레이아웃 이동이 없을 때만 나머지 게임으로 확대한다.
- `/games` 목록 하단 광고는 목록 트래픽이 충분할 때 추가한다.
- 한 화면에 광고 슬롯은 최대 1개로 유지한다.

## 구현 단위

승인 후에도 새 광고 시스템을 만들지 않는다.

1. 기존 `AdSlot`을 실제 AdSense 슬롯으로 교체한다.
2. 공략 페이지에 공용 슬롯 1개를 추가한다.
3. 공용 `GameOverActions` 아래에 결과 전용 슬롯을 둘 수 있게 최소한의 선택 속성만 추가한다.
4. 게임별 `phase`가 `result`일 때만 해당 속성을 넘긴다.
5. idle/result/playing 상태별 광고 유무 테스트를 각각 1개씩 둔다.

## 완료 조건

- 플레이 중 네트워크 요청과 광고 DOM이 모두 없다.
- 광고가 게임 영역의 크기를 줄이거나 덮지 않는다.
- 재도전 버튼은 광고보다 먼저 보이고 즉시 동작한다.
- 모바일 390px, 노트북 1440px, 초광폭 화면에서 겹침과 가로 스크롤이 없다.
- 광고 차단기 사용 시 빈 테두리나 `광고 영역` placeholder가 남지 않는다.
- 광고 전후 핵심 지표를 같은 기간 기준으로 비교할 수 있다.
